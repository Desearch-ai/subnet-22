DaniLabs SN2 validator

Validator software for Bittensor Finney subnet 2. The worker verifies signed performance reports against finalized chain state and scores miners by workload.

Requirements

Use an Ubuntu 24.04 LTS CPU host (x86-64 or ARM64) with systemd. The recommended minimum is 4 vCPUs, 8 GB RAM, and 50 GB SSD. Have sudo and curl available and allow outbound HTTPS and WSS connections.

Install

curl -fsSLo install-danilabs-validator.sh https://raw.githubusercontent.com/DaniLabsAI/subnet/main/deploy/install-validator.sh && sudo bash install-danilabs-validator.sh

Installation starts the worker, verifies a finalized report, and enables automatic updates. A successful install prints the Git commit and report ID.

Operate

sudo systemctl status danilabs-sn2-validator.service danilabs-sn2-update.timer
