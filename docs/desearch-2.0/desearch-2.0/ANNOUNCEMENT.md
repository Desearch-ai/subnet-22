**Desearch 2.0: a web index built through open competition**

In 1.0, miners and validators delivered useful search. But answers could take too long, and external dependencies limited what we could retain and improve.

2.0 builds an organized, refreshed collection of company websites, news, articles and other web information. Fast search comes first; the same data can later support specialized datasets and other AI systems. Preparing data before queries arrive is intended to reduce waiting and make accepted work reusable.

Why Bittensor? To bring more contributors into building useful data and improving retrieval technology through open competition.

The first task family, crawling, is now running on SN22: miners fetch assigned pages and upload the extracted text, and validators check a sample of every upload. Content preparation and embeddings (search representations) from a selected model come next. The team operates the index and API at first. Valid work qualifies for rewards before customer deployment.

We plan to expand beyond these tasks. Possible later programs include model training, fine-tuning and reranking; their sequence and terms are not set.

Embedding miners and validators checking embeddings will need GPU capacity. The model and tested hardware requirements are not final. Do not buy equipment based on this proposal.

Crawling replaces AI and X search as SN22's work. Validators move over automatically through `run.sh`; miners switch to the crawl miner ([miner setup](../../miner-setup.md)). No other program is open yet.
