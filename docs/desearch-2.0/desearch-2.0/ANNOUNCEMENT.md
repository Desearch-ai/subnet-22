**Desearch 2.0: a web index built through open competition**

In 1.0, miners and validators delivered useful search. But answers could take too long, and external dependencies limited what we could retain and improve.

2.0 would build an organized, refreshed collection of company websites, news, articles and other web information. Fast search comes first; the same data can later support specialized datasets and other AI systems. Preparing data before queries arrive is intended to reduce waiting and make accepted work reusable.

Why Bittensor? To bring more contributors into building useful data and improving retrieval technology through open competition.

The first tasks would cover crawling, content preparation and embeddings (search representations) from a selected model. Miners would build the data; validators would check it. The team would initially operate the index and API. Valid work can qualify for rewards before customer deployment.

We plan to expand beyond these tasks. Possible later programs include model training, fine-tuning and reranking; their sequence and terms are not set.

Embedding miners and validators checking embeddings will need GPU capacity. The model and tested hardware requirements are not final. Do not buy equipment based on this proposal.

This proposal does not change current SN22 operations or open a new reward program.
